Hack Club Stardance Blog

A full-stack blog application built for the Hack Club Stardance mission. Features email/password authentication powered by Better Auth and persistent storage via MongoDB.

## Tech Stack

- **Framework:** Next.js (App Router, TypeScript)
- **Database:** MongoDB (Mongoose)
- **Authentication:** Better Auth
- **Styling:** Inline CSS & Tailwind CSS

## Features

- User Authentication (Sign Up & Sign In)
- Persistent Database Connection via Mongoose
- Blog Post Creation Interface
- Home & Blogs Feed Pages
